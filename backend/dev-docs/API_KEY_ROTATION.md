# API Key 手动轮转

在 **API 密钥** 页找到要更换的 Key，点击 **轮转** 并确认。服务端在原记录上生成替代密钥，不改变 Key ID、分组、状态、有效期、额度、用量或历史记录。

轮转成功后，旧 Key 不再用于新请求。请立即复制保存只显示一次的新 Key，并更新客户端配置。已禁用或过期的 Key 不会因轮转重新启用。如果没有保存新 Key，可以重新发起轮转。

## 接口

- `POST /api/v1/keys/:id/rotate`：使用登录会话认证，只能轮转自己名下的 Key；无请求体。
- 请求头 `Idempotency-Key` 必填。每次发起新的轮转应使用新的操作 ID；重试同一次请求应复用原 ID。
- 首次成功响应中，`data` 包含 `id`、`key_hint` 和新凭证 `key`。幂等重放只返回 `id` 与 `key_hint`，不会再次轮转，也不会返回完整 Key。
- 响应设置 `Cache-Control: no-store`。列表和详情仍只返回掩码，不返回完整 Key。
